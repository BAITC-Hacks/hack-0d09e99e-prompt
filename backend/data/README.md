# Данные

Qor не поставляется с чужим каталогом. Менеджер выгружает Excel из 1С и загружает их в `/import` — оттуда считается заказ. Результат расчёта: `backend/data/workspace.json` (не коммитится). Сырые файлы: `backend/data/uploads/`.

Модель спроса обучается отдельно. Веб вызывает `backend/run_workspace.py`.
